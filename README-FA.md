# شیپا — پایلوت بومی اندروید ۰.۵.۰

همان پروژه و شناسه برنامه `ir.shipaa.mobile`، محدود به دوره ۱۷۴.

## پیاده‌سازی
- خانه یادگیری فارسی و RTL با چهار نمای یادگیری، جلسات، پیشرفت و حساب.
- Media3 1.5.1: پخش بومی، کنترل سرعت، حرکت ۱۰ ثانیه‌ای، تمام‌صفحه افقی، مدیریت audio focus و قطع هدفون؛ توقف در پس‌زمینه.
- خواندن جلسات و موقعیت قبلی از API واقعی موتور نصب‌شده؛ کنترل دسترسی پیش از انتخاب هر جلسه و هر ۶۰ ثانیه هنگام حضور در محیط یادگیری.
- ذخیره پیشرفت هر ۱۵ ثانیه، هنگام توقف و تغییر جلسه؛ صف محلی خصوصی به تفکیک شناسه کاربر، ارسال مجدد بعد از دریافت نشست معتبر.
- درصد جلسه پس از مشخص‌شدن مدت ویدیو؛ درصد دوره بر اساس تعداد جلسات تکمیل‌شده. تکمیل خودکار در پایان ویدیو.
- صفحات عمومی فقط WebView با منوی خود سایت؛ منوی بومی و هدر در آن‌ها پنهان است. برگشت گوشی تاریخچه سایت را طی می‌کند و سپس به یادگیری بازمی‌گردد. لینک آزمایشی دوره ۱۷۴ به محیط بومی هدایت می‌شود.

## احراز هویت
ورود در WebView خود سایت است. کوکی معتبر وردپرس از CookieManager فقط برای مبدأ HTTPS سایت استفاده می‌شود. `admin-ajax.php?action=rest-nonce` nonce نشست جاری را فراهم می‌کند؛ nonce به‌تنهایی احراز هویت نیست. `users/me` هویت را تعیین می‌کند و موتور آموزش مجوز دوره را کنترل می‌کند. رمز، توکن ثابت، nonce و نشانی ویدیو در SharedPreferences یا سورس ذخیره نمی‌شوند. کوکی‌ها به هاست ویدیو ارسال نمی‌شوند. REST از redirect پیروی نمی‌کند. backup برنامه خاموش است.

مستندات رسمی: https://developer.wordpress.org/reference/functions/wp_ajax_rest_nonce/ و https://developer.wordpress.org/rest-api/using-the-rest-api/authentication/

## قرارداد مشاهده‌شده
GET `/wp-json/shipaa-learning/v1/course/174/session`:
`{course_id,title,lessons:[{id,title,summary,video_url,progress:{seconds,completed}}],pilot}`

POST `/wp-json/shipaa-learning/v1/course/174/progress`:
`{lesson_id:string,seconds:number,completed:boolean}`

API در حساب مدیریتی پاسخ ۲۰۰ داد. هر دو جلسه فعلی به یک فایل اشاره می‌کنند؛ محتوا باید توسط مدیر بررسی شود. API مدت، تصویر دوره یا فهرست همه دوره‌های فعال را عرضه نمی‌کند.

## ساخت
GitHub Actions با push روی شاخه آزمایشی اجرا می‌شود: assembleDebug و lintDebug، بررسی ZIP فایل APK و آپلود artifact با نام `shipaa-mobile-v0.5.0-native-debug-apk`.
خروجی: `app/build/outputs/apk/debug/app-debug.apk`.

## گیت آزمایش واقعی — هنوز تأیید نشده
1. نصب روی Xiaomi 12، ورود دانشجوی عادی مجاز و دریافت هر دو جلسه.
2. کاربر بدون خرید/تأیید و کاربر خارج‌شده نباید جلسه دریافت کند؛ انقضای نشست و لغو دسترسی وسط پخش بررسی شود.
3. خروج از برنامه و بازگشت؛ ادامه از محل ذخیره، تغییر دستگاه، قطع و وصل اینترنت، پایان جلسه و عدم انتقال پیشرفت بین دو حساب.
4. سرعت، seek، تماس، قطع هدفون، تمام‌صفحه و برگشت؛ منوی تکی در تمام صفحات.
5. دسترسی دانشجو به admin-ajax و users/me ممکن است توسط تنظیمات امنیتی سایت محدود باشد؛ در این صورت به اصلاح حداقلی سرور نیاز است، نه دورزدن کنترل آن.
6. امنیت فایل‌های هاست ویدیویی جدا از مجوز API است. نشانی مستقیم صادرشده توسط موتور، حفاظت هر درخواست بایت ویدیو را تضمین نمی‌کند؛ صدور URL کوتاه‌عمر یا تحویل محافظت‌شده در هاست باید جداگانه بررسی شود. برنامه هیچ URL پولی را در سورس ندارد و حفاظت کامل محتوا ادعا نمی‌کند.

## خارج از این تحویل
کش ۵۰۰ مگابایتی/۴۰ دقیقه، پخش آفلاین، تصویر دوره و فهرست سایر دوره‌ها هنوز پیاده نشده‌اند. تصویر پروفایل از avatar_urls وردپرس خوانده می‌شود؛ در نبود تصویر قابل دریافت، آیکون خنثی نمایش داده می‌شود. مدیریت پروفایل از حساب سایت قابل دسترس است. هیچ تغییر زنده‌ای در وردپرس یا داشبورد انجام نشده است. APK آزمایشی debug است؛ امضای انتشار پایدار و سازگاری امضا با نصب قبلی باید بررسی شود.
